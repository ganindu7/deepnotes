Labels

where a step begins
One label to the next is one atomic step; other processes run only at a label. Too few labels hide bugs, too many add states but stay sound.
Required: the first statement of the body, each process, each procedure; every while; after goto, call, return; a second write to a variable in a step (or use ||); after an if / either containing a label.
Forbidden inside with and a macro. All are reported as Missing label at … with a line and column.
